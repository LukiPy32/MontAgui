MontAgui v3

Versión enfocada en SEO técnico previo a publicación definitiva.

Cambios principales:
- Título SEO orientado a búsquedas locales: metalúrgica, corte láser y plegado en Bahía Blanca.
- Meta description optimizada.
- Eliminado meta keywords (Google no lo utiliza para posicionamiento).
- Meta robots para indexación.
- Open Graph básico para redes sociales.
- Datos estructurados Schema.org LocalBusiness con dirección, ciudad, Instagram y servicios.
- robots.txt preparado.
- Precarga de la imagen principal y atributos de rendimiento en imágenes.

Pendiente cuando exista dominio o URL pública definitiva:
- canonical.
- og:url y og:image absolutos.
- sitemap.xml definitivo.
- URL/logo/image absolutos dentro de los datos estructurados si se desea máxima compatibilidad.
- Alta y verificación en Google Search Console.
- Vinculación con Perfil de Empresa de Google si corresponde.

No se inventaron teléfono, horarios, años de experiencia ni otros datos comerciales todavía no confirmados.
